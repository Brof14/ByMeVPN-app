# DESIGN SYSTEM & UI GUIDELINES — BYMEVPN ANDROID

**Версия:** 2.1 (Refined & Production Polish)  
**Продуктовая концепция:** Минималистичный, технологичный и надёжный VPN-клиент коммерческого уровня.  
**Слоган:** *«Скорость. Свобода. Простота.»*

---

## 1. Философия и характер бренда

Интерфейс ByMeVPN строится на четырёх ключевых принципах:
1. **Честность состояний (State Transparency):** Интерфейс отражает исключительно подтверждённое состояние туннеля и прав доступа. Никаких фиктивных пингов, поддельных графиков или ложных обещаний «защита активна», пока соединение не верифицировано.
2. **Тактильная отзывчивость (Physical Fluidity):** Следуя принципам `emil-design-eng` и `apple-design`, любой интерактивный элемент реагирует на касание мгновенно в момент нажатия (`pointer-down`), уменьшаясь на 3–4% (`scale(0.96f)`) с плавным возвратом. Ключевые действия сопровождаются нативной тактильной отдачей (`HapticFeedback`).
3. **Визуальная сдержанность (Restrained Aesthetic):** Полный отказ от кислотного неона, избыточного псевдо-киберпанка и перегруженных карточек. Основа палитры — глубокий тёмный космос, графитовые поверхности и один акцентный мятно-изумрудный цвет (`BrandMint`).
4. **Скорость и фокус (Zero Latency UX):** Время анимаций интерфейса не превышает 250–300 мс с использованием выразительной кривой `CubicBezierEasing(0.23f, 1f, 0.32f, 1f)`. На главном экране пользователю в один взгляд понятно: включён ли VPN, куда он подключён, какова скорость и сколько дней подписки осталось.

## 3. Компонентная система

### 3.1. Кнопка включения VPN (`VpnPowerButton`)
- **Размер:** Адаптивный, диаметр до 280 dp с сохранением пропорций 1:1.
- **Интерактивность:**
  - При нажатии (`pointer-down`) немедленно сжимается до `0.96f` через `remember { MutableInteractionSource() }`.
  - При срабатывании вызывается тактильный отклик (`LocalHapticFeedback.current.performHapticFeedback(HapticFeedbackType.LongPress)`).
  - При смене состояния с Disconnected на Connected запускается органичный импульс расширения внешнего кольца (`successPulseKey`).
  - В состоянии `CONNECTING` включается мягкая бесконечная пульсация (`0.98f .. 1.02f`) и вращающийся тонкий индикатор.

### 3.2. Панель телеметрии и скорости (`LiveSpeedWave` & `TelemetryDock`)
- При подключённом VPN под таймером отображается информативная карточка реальной скорости:
  - Скорость загрузки (↓ Mbit/s или KB/s) и отдачи (↑).
  - Общий объём переданных за сессию данных (MB / GB).
  - Мягкая синусоидальная волна сетевой активности, визуализирующая прохождение пакетов через туннель.

### 3.3. Карточка сервера (`ServerCard`)
- Флаг страны (векторная отрисовка 26×26 dp с закруглёнными углами).
- Отображение города и страны (с обрезкой по многоточию при экстремальной длине).
- Бейдж протокола (VLESS Reality / Hysteria 2).
- Индикатор качества связи с реальным пингом в миллисекундах.

### 3.4. Экран расширенных настроек (`AdvancedSettingsScreen`)
- Группировка настроек по смысловым блокам:
  1. **Сеть и протокол:** выбор DNS-режима (Cloudflare 1.1.1.1 / AdGuard без рекламы / Google 8.8.8.8), протокольные параметры.
  2. **Поведение туннеля:** автоматическое переподключение при сбоях сети, прямой маршрут для сайтов РФ.
  3. **Уведомления и интерфейс:** отображение текущей скорости в шторке Android, тактильная отдача.
  4. **Безопасность системы:** переход в системные настройки Android для включения Always-on VPN и Kill Switch.

## 4. Правила анимаций и доступности

1. **Easing:** Для всех UI переходов используется кривая `CubicBezierEasing(0.23f, 1f, 0.32f, 1f)` — быстрый старт с плавным оседанием.
2. **Spring Physics:** Для жестов и шторки серверов применяется `spring(dampingRatio = 0.85f, stiffness = Spring.StiffnessMediumLow)`.
3. **Accessibility:**
   - Все кликабельные элементы имеют минимальный touch target не менее `48.dp`.
   - Семантические свойства `Role.Button`, `Role.RadioButton` и текстовые `contentDescription` для программ чтения экрана (TalkBack).
   - Поддержка системного масштабирования шрифтов (`LocalDensity.current.fontScale`) без выпадения и наложения текста.
